# Product

## Register

product

## Users

Self-hosters and their invited readers use Sake to manage a personal or household ebook library across the web app and KOReader devices. Administrators configure one server instance and expect provider settings to apply consistently to every user and device.

## Product Purpose

Sake provides a private, self-hosted reading library with search, downloads, device sync, and reading tools. Settings should let an administrator adapt external-provider connections without requiring source changes or redeployment.

## Brand Personality

Calm, capable, and private. The interface should feel dependable during configuration work and concise during routine library tasks.

## Anti-references

Avoid decorative dashboard treatment, settings hidden behind ambiguous controls, and vendor-style complexity that obscures the active configuration. Do not make routine configuration feel like a developer console.

## Design Principles

- Keep administrative configuration explicit and reversible.
- Show ordering and active behavior where it affects outcomes.
- Preserve familiar product controls and compact settings density.
- Make failures actionable without exposing provider internals.
- Keep server-wide effects clear to administrators.

## Accessibility & Inclusion

Meet WCAG AA. Every setting must be keyboard-operable, use explicit labels and instructions, retain clear focus states, and communicate validation and failover outcomes without relying only on color.
